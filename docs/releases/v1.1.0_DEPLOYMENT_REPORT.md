## Summary of Changes

v1.1.0 introduces a comprehensive deployment reliability framework that
addresses the root causes of the 2026-07-28 production incident. This release
adds **zero new features** — it is purely operational infrastructure.

### Integrity Gates (Pre-Deployment)

Three new integrity gates run before every production deployment:

| Gate | Tool | What It Validates |
|------|------|-------------------|
| Repository Integrity | `scripts/repo-integrity-check.sh` | Clean git state, no merge conflicts, no untracked build artifacts |
| Required Files | `scripts/required-files-check.sh` | wrangler.jsonc, tsconfig.json, required secrets, build scripts |
| Import Resolution | `scripts/import-integrity-check.py` | All import paths resolve correctly across the codebase |

### Pre-Commit Hook

- Installed at `.git/hooks/pre-commit`
- Runs all 3 integrity gates before allowing commits
- Fail-closed: any gate failure blocks the commit
- Exclusions: `artifacts/`, `lib/`, `hermes-website/`, `__tests__/`, `workers/tests-epic0059/`

### CI/CD Pipeline

The deploy.yml workflow now has 10 distinct steps with 4 security gates:

1. Source checkout
2. Toolchain setup (pnpm + Node.js 22)
3. Dependency installation
4. 🔒 **Gate — Repository Integrity**
5. 🔒 **Gate — Required Files**
6. 🔒 **Gate — Import Resolution**
7. Frontend build
8. 🔒 **Guard — Production Bundle Verification**
9. JWT injection + API worker deploy
10. Frontend worker deploy
