# v1.1.0 Pre-Deployment Checklist

> **Document:** Operator checklist for production deployment
> **Version:** v1.1.0
>
> Run these checks **IN ORDER**. Each gate must pass before proceeding to the next.

---

## Phase 1 — Local Verification (Developer)

```bash
# Before committing any changes
```

| # | Check | Command | Pass/Fail |
|---|-------|---------|-----------|
| 1 | Git status is clean | `git status` | |
| 2 | No stash conflicts | `git stash list` | |
| 3 | Branch is correct | `git branch --show-current` (should be `main`) | |
| 4 | Pre-commit hook passes | `git commit` passes all 3 integrity checks | |
| 5 | Dry-run deploy passes | `bash scripts/dry-run-deploy.sh` | |

---

## Phase 2 — Pre-Deployment (Operator)

```bash
# Before triggering the CI/CD pipeline
```

| # | Check | How | Pass/Fail |
|---|-------|-----|-----------|
| 1 | JWT secrets in GitHub | Check repo Settings → Secrets → Actions | |
| 2 | VITE_API_BASE in secrets | Value should point to `https://api.agsynergy.ca` | |
| 3 | Cloudflare API token valid | Generate fresh Workers token if >30 days old | |
| 4 | Target branch is `main` | Only `main` triggers production deploy | |
| 5 | No open PRs against `main` | GitHub PRs page | |

---

## Phase 3 — CI/CD Pipeline (Automated)

The pipeline at `.github/workflows/deploy.yml` runs these checks automatically:

| Step | Gate | Fail Action |
|------|------|-------------|
| 🔒 Gate 1 — Repo Integrity | `scripts/repo-integrity-check.sh` | Blocks deploy |
| 🔒 Gate 2 — Required Files | `scripts/required-files-check.sh` | Blocks deploy |
| 🔒 Gate 3 — Import Resolution | `scripts/import-integrity-check.py` | Blocks deploy |
| Build | `pnpm run build` | Blocks deploy |
| 🔒 Gate 4 — Bundle Guard | Verifies production host in bundle | Blocks deploy |
| Inject JWT + Deploy API | `wrangler deploy --env production` | Blocked by prior gates |
| Deploy Frontend | `wrangler deploy` (root) | Blocked by prior gates |

---

## Phase 4 — Post-Deployment Verification (Operator)

```bash
# Immediately after deploy completes
```

| # | Check | Command / URL | Pass/Fail |
|---|-------|---------------|-----------|
| 1 | Health endpoint | `curl https://api.agsynergy.ca/api/v1/health` | |
| 2 | Frontend reachable | Visit `https://agsynergy.ca` in browser | |
| 3 | Auth flow | Test login at `https://agsynergy.ca/login` | |
| 4 | Run deployment summary | `bash scripts/deployment-summary.sh` | |
| 5 | Review summary report | `cat docs/releases/deployment-summary-<SHA>.md` | |
