## Overview

v1.1.0 introduces a comprehensive deployment reliability framework for the
Concierge platform. This release adds automated integrity gates, pre-commit
validations, and operational tooling to prevent the class of failure that
caused the 2026-07-28 production incident.

**No feature changes.** This release is exclusively deployment
infrastructure.

---

## What's Changed

### New: Integrity Gate System

Three pre-deployment integrity gates that run sequentially:

| Gate | Tool | What It Checks |
|------|------|----------------|
| Repository Integrity | `repo-integrity-check.sh` | Git state, unstaged changes, untracked files |
| Required Files | `required-files-check.sh` | wrangler configs, wrangler TOML, tsconfig, secrets |
| Import Resolution | `import-integrity-check.py` | All tracked files resolve their imports |

### New: Pre-Commit Hook

- Installed at `.git/hooks/pre-commit`
- Runs all 3 integrity gates before every commit
- Fail-closed: blocks commit if any gate fails
- Prevents broken code from entering the commit log

### New: CI/CD Pipeline Upgrades (deploy.yml)

Previous pipeline: `checkout → install → build → deploy` (no gates)

New pipeline (10 steps):
1. Checkout
2. Toolchain setup
3. Dependencies
4. 🔒 Gate — Repo Integrity
5. 🔒 Gate — Required Files
6. 🔒 Gate — Import Resolution
7. Build frontend
8. 🔒 Guard — Production bundle verification
9. Inject JWT + Deploy API worker
10. Deploy frontend worker

### New: Operational Scripts

| Script | Purpose |
|--------|---------|
| `scripts/dry-run-deploy.sh` | Pre-flight deploy validation |
| `scripts/deployment-summary.sh` | Post-deploy report generation |

### Security: `.gitignore` Update

- Added `__pycache__/` and `*.pyc` to prevent committed cache files

## Deployment Notes

1. **JWT secrets** must be set in GitHub Secrets (JWT_PRIVATE_KEY, JWT_PUBLIC_KEY, JWT_KID)
2. **CLOUDFLARE_API_TOKEN** must be a valid Workers token (100-char, not the 53-char legacy format)
3. **VITE_API_BASE** must be set to `https://api.agsynergy.ca`
4. Run `bash scripts/dry-run-deploy.sh` before triggering CI/CD
5. Run `bash scripts/deployment-summary.sh` after deploy for audit report
